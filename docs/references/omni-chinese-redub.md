# Omni 纯中文人物口播后期配音

本规则是用户为 OpenMontage 指定的项目默认，适用于 Google Omni / Flow
新生成的人物口播画面。保留人物表演，只有纯中文口播才替换配音并对齐原声节奏。
不据此推断模型训练语料，也不固定声线、时长或变速倍率。

## 语言分流

以本次视频的完整口播为单位，根据批准的台词判定语言，不只看某个镜头或子句。

| 完整口播语言 | 默认处理 |
|---|---|
| 纯中文 | 必须生成独立中文配音，替换原生对白，并按原声分短语对齐 |
| 纯英文 | 直接保留原声；不进入换配音、节奏对齐、嘴型同步或听感专项检查 |
| 混合语言 | 整条保留原声；不拆出中文段，不进入上述处理与专项检查 |
| 其他语言 | 沿用该生产已有的声音方案，不自动套用中文规则 |

纯英文和混合语言到此结束本流程，不为它们调用 TTS、转写或同步工具。
视频文件、解码和画面等既有技术检查照常；字幕若有明确需求，沿用字幕流程。
外部提供的视频、已经独立生成的旁白、无口播片段不自动再次换声。
用户对当前生产的明确声音要求优先；已接受的历史素材不因新增规则重跑。

## 纯中文执行方法

1. **先生成原生人物口播。** 保持已选择的 Google 路径，提示人物说出批准的
   中文台词并保留原生对白，用它提供嘴部表演和实际发音节奏。保存原片和生成回执。
2. **生成独立中文配音。** 沿用项目的 `tts_selector` 或已明确选定的 TTS 工具，
   台词逐字不变，声线按该生产的决定传入。已有接受的配音可以复用，
   不通过合成引擎重新调用 TTS。执行已授权生产时，中文换声是默认步骤，
   无需逐条另问是否换声；方案请求仍只做方案。
3. **提取原声时间参照。** 将原片对白和新配音解码，标出可确认的短语起止、
   句内停顿和说完后的留白。转写只辅助确认文字与短语，普通 ASR 的逐字时间
   可能吞入静音，不能直接据此剪掉字头或把停顿拉成一个长音节。
4. **分短语变速并还原停顿。** 保持原视频的帧和运动速度，优先处理音频。
   每段 `tempo = 新配音段时长 / 原声目标段时长`：大于 1 加快，小于 1 放慢；
   使用 FFmpeg `atempo` 等保持音高的处理，把各段放回原声位置，补足原声的
   停顿与尾部留白。保留低能量字头、尾音，接缝使用短淡入淡出。
   不能只对齐整句话首尾，也不能把小样的某个倍率套给全部台词。
5. **替换最终对白。** 用 `audio_mixer` 和既定合成入口完成混音，去掉原生对白，
   避免两个人声叠加。音乐、环境声沿用已批准的声音方案。
   字幕和剪辑时间使用最终对齐后的配音，不能沿用原始 TTS 的时间戳。
6. **复核中文结果。** 检查实际成片中的停顿、继续说话、发音和听感，确认没有
   截断音节或因拉伸产生明显不自然。波形停顿接近不等于逐音素嘴型已验收。
   若分短语对齐仍不足，只在已有工具和当前授权覆盖时细化对齐或做嘴型驱动；
   不因未配置唇形工具而重生整段画面或静默更换供应商。

## 工件与交接

在 `decision_log` 记录完整口播语言和处理分支。纯中文资产记录原视频、
原声参照、新配音、对齐后音频的路径与哈希，以及 TTS 工具、模型和声线。
保存项目内的对齐回执，包含每段源/目标时间、实际倍率、停顿、最终输出和验收范围，
让 `asset_manifest` 与 `edit_decisions` 引用最终音轨。
沿用当前流水线的渲染、检查和交付入口，不另建生产管线或增加审批关卡。
