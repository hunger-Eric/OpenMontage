# Talking-head and lip-sync assets

This is an explicitly requested specialty capability, not the default video
route. Read `creative/talking-head-gen-usage.md` or `creative/lip-sync-usage.md`
under `skills/`, then inspect the actual registry for available talking-head or
lip-sync tools and their provider-specific instructions. Kling tools use
`kling-official`; local tools use their own declared dependencies.

Use authorized source media and generated narration, save assets inside the
project, and review decoded identity, mouth motion and audio alignment. Preserve
original task identities after uncertain submissions. If the requested capability
is unavailable, report that boundary; never silently change provider or claim
that a generic image-to-video clip proves lip-sync acceptance.
